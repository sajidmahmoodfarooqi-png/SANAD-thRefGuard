1What SANAD is

SANAD is a citation-integrity companion for anyone writing a thesis, dissertation, or paper in Microsoft Word or LibreOffice. It does one thing that ordinary reference managers don't: it checks that every citation is right — the right source, cited in the right place — not merely formatted correctly. And it does all of it on your own machine.

It checks meaning, not just formatBeyond "does this look like APA?", SANAD asks "is this the correct source, and does it belong in this sentence?"
It formats to your handbookBuild a style profile from your university's rules — citation style, fonts, margins, headings — not a generic preset.
It never touches your proseSANAD only ever writes inside its own citation and reference fields. Your sentences are guaranteed untouched — enforced in code.

Everything runs locally. There is no account, no cloud, and no telemetry; your library is a single file on your computer, and the engine makes no outbound network connections.

2Install & first run

  1. Run the installer for your platform (Windows .exe, macOS .dmg, or Linux AppImage) and launch SANAD.
  2. On first launch the app starts its local engine (the "Core"). A status light in the app turns green when the Core is ready — this usually takes a second or two.
  3. You're ready. Nothing to sign into. Open Library → Add source and either paste a few references or choose Load a small sample set to explore.
What gets installed. SANAD is fully self-contained — the engine and everything it needs ship inside the app. Your library lives in your user data folder and stays there when you update or uninstall.

4Building your library

Your library is the set of sources SANAD checks against. Fill it however suits you:

  • Paste RIS or BibTeX — both export from Zotero, Mendeley, EndNote, and every other reference manager. Open Library → Add source, choose the format, and paste.
  • Drop a list file — a well-formatted reference list as Excel (.xlsx), CSV, or Word (.docx) can be imported directly.
  • Typed list — paste a plain numbered list of references and SANAD parses it.

De-duplication (rule R6)

SANAD stores everything locally and de-duplicates safely. Re-importing the same reference collapses to a single entry, but two genuinely different works are never silently merged — likely duplicates are flagged for you to review. If you accidentally import a file twice, open Library → De-duplicate to collapse the extras.

Optional DOI look-up (Crossref)

SANAD can enrich a reference from its DOI using the public Crossref service. This is the one feature that reaches the internet, so it is off by default and only ever runs when you explicitly ask for it on a specific reference. With it off, SANAD is completely offline.

5Style profiles

A style profile captures your target format. Instead of a generic "APA", you build a profile that matches your university's thesis handbook. Go to Style profiles → New profile and set:

Base styleThe citation style everything derives from — search 10,000+ styles (APA, MLA, Chicago, Harvard, IEEE, Vancouver, or a specific journal).
"et al." fromHow many authors before the list is shortened.
Ampersand in textUse the word "and" instead of "&".
Reference fontFont family and size for the bibliography.
Hanging indentThe reference-list indent, in centimetres.
Page marginThe document margin, in centimetres.
Line spacingSingle, 1.5, or double.

A profile is a small, shareable file. Save it once and apply it to any document.

Headings — Word's Styles gallery

A profile can also carry your heading styles, mapped onto Word's own Styles gallery: Title and Heading 1–3. For each level you set a font and a size; leave a heading's font blank to reuse the body font.

Turn on "Number headings automatically" and SANAD applies Word's standard multilevel scheme:

1  Introduction  — Heading 1
1.1  Background  — Heading 2
1.1.1  Prior work  — Heading 3
1.2  Aims  — Heading 2
2  Methods  — Heading 1

Because these land on the document's real Word styles, the numbers renumber themselves automatically as you add, remove, or reorder chapters — you never type or maintain a number by hand. And, like everything else here, applying them changes not one word of your heading text: Word renders the numbers, they are never inserted into your prose.

Tip. For the numbering to attach, your headings must actually use Word's Heading 1 / 2 / 3 styles (the Styles gallery on the Home ribbon), not manually enlarged bold text. If they do, everything just works.

6Format your thesis

The Format screen takes your finished .docx and a style profile, and returns the same document reformatted to that profile — body font, size and line spacing; page margins; Title and Heading 1–3 fonts, sizes and numbering; and a hanging indent on the reference list.

  1. Open Format, pick a style profile, and drop or choose your document.
  2. SANAD reformats it and gives you the new file, listing exactly what it changed.
The reference-list indent needs one thing from you. The hanging indent is applied to Word's built-in Bibliography style. If your reference list uses that style, the indent lands automatically; if not, SANAD tells you so rather than guessing which paragraphs are references.
The guarantee, restated. This whole pass only ever writes style and format properties — never paragraph text. SANAD fingerprints every word before and after and refuses to save if a single character of prose would change. It also runs with the network sealed off, so your document cannot leave the machine while being processed.

7The Word add-in

The desktop app manages your library, profiles, and formatting. To insert citations and run checks inside your document, use the SANAD task pane in Word. It is a thin client: it talks only to your local Core and writes only inside its own tagged fields — never your prose.

Connect it

  1. Keep the SANAD desktop app running (it hosts the Core).
  2. Copy the session token from the desktop app's Settings screen.
  3. In Word's task pane, open Connect, paste the token, and click Connect. The status goes green.

Use it

  • Insert — search your library and drop a citation at the cursor (wrapped in SANAD's own sanad-cite field).
  • Reference list — rebuild the whole bibliography from the document's citations, in your profile's format, inside the single sanad-bibliography field.
  • Integrity — run the Tier-A and Tier-B checks over every citation in the document.
Installing the pane. The task-pane files are hosted on a web address (the project's GitHub Pages site or your own HTTPS host) and loaded into Word via its manifest — only the pane's interface comes from the web. Your document never leaves your machine: the pane talks solely to the local Core on 127.0.0.1. See the project's connectors/word README for the exact sideload steps.

8The integrity check

This is what makes SANAD different. After a citation looks right, SANAD checks whether it is right. Every finding is a card with a severity, a plain-English explanation, and actions — nothing is ever changed automatically. Press Run a demo check on the Integrity screen to see it work on a sample.

RuleWhat it catchesWhat to do
R1 — Year mismatchThe year you typed doesn't match the source in your library.Pick the correct year.
R2 — Venue looks wrongA book resolved to a review of the book, not the book itself.Re-resolve or replace the source.
R3 — Orphaned citationA citation points to a source no longer in your library.Relink it, or remove it.
R4 — Cited not listedA source in a grouped citation would drop out of the reference list.Restore the missing source.
R5 — Listed not citedA reference sits in the list but nothing cites it.Cite it, or remove it.
R6 — Possible duplicateTwo library entries look like the same work.Merge, or keep both.
R7 — Ambiguous author/yearTwo sources share author + year with no a/b suffix.Add a/b suffixes.
R8 — Cited out of contextThe sentence is about one topic but cites an unrelated source — a closer one may be in your library.Review the suggestion. SANAD suggests, you decide.

R8 is the semantic check. If the optional language model is available it compares meaning (catching paraphrases); if not, it falls back to a lighter word-overlap check — still useful, just less sensitive. Either way, R8 only ever suggests.

9Privacy & your data

  • Everything is local. Your library is a single file on your machine.
  • No network egress. The engine listens only on 127.0.0.1 and makes no outbound connections — except the DOI look-up in §4, which is off unless you turn it on.
  • No account, no cloud, no telemetry. Nothing about your work is collected or sent anywhere.
  • A per-launch token guards the engine, so no other program or web page on your computer can reach your library.

10Troubleshooting

Status light is redThe engine didn't start — quit and reopen SANAD. If it persists, another program may be using port 23890.
Import did nothingCheck the chosen format matches what you pasted (RIS vs BibTeX). A plain numbered list should use Typed list.
Doubled referencesYou likely imported a file twice — open Library → De-duplicate.
Heading numbers didn't appearYour headings must use Word's real Heading 1/2/3 styles for numbering to attach (§5).
Reference indent skippedApply Word's Bibliography style to your reference list, then reformat (§6).
Add-in won't connectMake sure the desktop app is running, and re-copy the current session token from Settings (it changes each launch).
R8 says "semantic check: off"The optional semantic model isn't installed, so a lighter word-overlap check was used. This is expected and fine.
