# Try SANAD in two minutes

A ready-made library and a short practice manuscript so you can see SANAD working without
building your own library first. All data here is **invented** — no real bibliography.

| File | What to do with it |
|---|---|
| [`sample-library.ris`](sample-library.ris) | Import into SANAD (**Library → Add source → RIS**). Ten references, with a planted duplicate and an ambiguous author/year so **Library health** has something to show. |
| [`sample-thesis.docx`](sample-thesis.docx) | Open in Word with the SANAD add-in. Insert citations where the 【insert citation …】 markers are, then run **Integrity** — the last section explains what each planted problem should trigger (R1, R2, R6, R7, R8). |

Regenerate the manuscript with `python examples/make_sample_docx.py`.
